# 🌾 Smart Crop Disease Diagnosis & Remediation Dashboard

An AI-powered agricultural web platform that helps smallholder farmers diagnose crop leaf diseases, receive step-by-step remediation plans, track recovery, and get weather-driven risk alerts[cite: 1, 2].

---

### 🚀 Core Features
* **AI Disease Detection:** Analyzes uploaded leaf images to return disease type, confidence score, and severity percentage[cite: 1, 2].
* **Weather Risk Alerts:** Forecasts disease risks using live humidity, rainfall, and temperature data[cite: 1, 2].
* **Crop Health Timeline:** Tracks recovery and compares severity across repeated image uploads[cite: 1, 2].
* **Multilingual & Voice Support:** Localized in English, Hindi, and Odia with speech-to-text input[cite: 1, 2].
* **Admin Heatmap:** Outbreak monitoring by village and district for agricultural officers[cite: 1, 2].
